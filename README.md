# 통합 과학 정리 노트

화학·기하·물리학을 분야별 독립 페이지로 정리한 학습용 웹 노트입니다.

## 페이지
- `index.html` — 통합 과학 홈
- `chemistry.html` — 화학 (4단원)
- `geometry.html` — 기하 (4단원, 이차곡선 캔버스 시각화 포함)
- `physics.html` — 물리학 (6단원)

## 공통 기능
- 분야 간 페이지 이동
- 검색
- 다크 모드
- KaTeX 수식 표시 및 수식 복사
- 화학 이상 기체 계산기
- 기하 공간좌표 거리 계산기
- 물리학 F=ma 계산기
